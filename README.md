# Backend Projects

A collection of backend projects built while learning and applying server-side development concepts.

Each project explores different backend concepts including REST APIs, database integration, validation, authentication, and backend architecture.

---

## Projects

## 📚 Library API

A RESTful API for managing a library system.

### Features

- Create, read, update, and delete books
- PostgreSQL database integration
- Request validation
- Middleware usage
- Environment variable configuration
- Partial updates using PATCH
- Modular Express project structure

### Technologies

- Node.js
- Express.js
- PostgreSQL
- pg
- dotenv
